# 📚 KTU Kütüphane Sistemi

Bu proje, **Karadeniz Teknik Üniversitesi (KTÜ)** için hazırlanmış basit bir **kütüphane yönetim sistemi** prototipidir.  
Amaç, kitapların, üyelerin ve ödünç işlemlerinin web tabanlı olarak takip edilebildiği bir sistem tasarlamaktır.

---

## 🚀 Özellikler
- Kitap ekleme, silme ve listeleme
- Üye yönetimi
- Ödünç alma ve iade işlemleri
- Geciken kitap takibi
- Yönetici paneli ve istatistik görünümü

---

## 🗂️ Dosya Yapısı
- 📁 images/ → Site görselleri
- 📄 anasayfa.html → Kullanıcıların gördüğü ana sayfa
- 📄 index.html → Panel
- 📄 kitaplar.html → Kitapların listelendiği sayfa
- 📄 uyeler.html → Üyelerin listelendiği sayfa
- 📄 islemler.html → Ödünç alma / iade işlemleri
- 📄 anasayfa.css → Ana sayfa stilleri
- 📄 style.css → Yönetim paneli ve genel stiller
- 📄 app.js → Gerekli JavaScript işlevleri
